## ما هذا المشروع؟

`FUGU-MAX` ليس بوتًا يتنبأ بالسعر، بل **مجمّع خبراء تكيّفي متصل (Adaptive Online Ensemble)**:

```
      بيانات بينانس USDⓈ-M (OHLCV + Funding + OI)
                        │
                        ▼
              ميزات سببية (Causal Features)
                        │
        ┌───────────────┴───────────────┐
        ▼                               ▼
   خبراء قواعدي                    خبراء تعلّميون
 (Momentum / Trend /            (Logistic SGD /
  Reversion / Flow /               RLS بنسيان أسّي)
        Volatility)
        └───────────────┬───────────────┘
                        ▼
              أوزان تكيّفية (Hedge / EG)
                        │
                        ▼
              سياق نظام السوق (Regime)
                        │
                        ▼
              اكتشاف الانجراف (Page-Hinkley)
                        │
                        ▼
                درجة FUGU-MAX  (-100 → +100)
                        │
                        ▼
              بوابة الميتا (Meta Filter)
                        │
                        ▼
              إدارة المخاطر وحجم المركز و SL/TP
```

الهدف المعلن للمشروع: **معرفة ما إذا كان التعلّم التكيّفي يضيف قيمة حقيقية مقابل Ensemble ثابت الأوزان** — لا الانبهار بالتعقيد.

## المحتويات

| الملف | الوظيفة |
|---|---|
| `config.py` | الإعدادات + قراءة المفاتيح من `.env` (لا أسرار في الشيفرة) |
| `data.py` | بيانات بينانس USDⓈ-M: شموع + فائدة تمويلية + عقود مفتوحة، ومولّد بيانات صناعية |
| `features.py` | 37 ميزة سببية بلا تطلّع للمستقبل |
| `labels.py` | التسميات الثلاث منفصلة: `signal` / `Triple-Barrier` / `meta` |
| `models.py` | الخبراء + أوزان Hedge + كاشف النظام + كاشف الانجراف |
| `strategy.py` | بوابة الميتا + حجم بالهدف التقلبي + SL/TP + مدير المخاطر |
| `backtest.py` | محرّك Walk-Forward صارم + مقاييس الأداء |
| `baselines.py` | الأنظمة المرجعية A/B/C/D/E للمقارنة |
| `fugu_indicator.py` | إشارة الآن، مفصّلة: لماذا، أوزان الخبراء، SL/TP |
| `train_and_report.py` | تقرير بحثي كامل + رسوم + حفظ حالة النموذج |
| `paper_engine.py` | المحرّك الحيّ (Paper افتراضيًا، أو تنفيذ على الديمو) |
| `exchange.py` | عميل بينانس USDⓈ-M موقّع (`demo` / `testnet` / `live`) |
| `observer.py` | مُسجِّل مستقل + Telegram — لا يعيد الحساب ولا يتداول |
| `telegram_test.py` | اختبار قناة المراقبة |
| `tests/` | 22 اختبار وحدة: منع التطلّع، المحاسبة، التجميد |

## كيف «يتعلّم ذاتيًا»؟

1. **كل شمعة مكتملة** تُحدّث كل خبير معاملاته: RLS بنسيان أسّي + Logistic SGD.
2. **Exponentiated Gradient (Hedge)**: الخبير الذي يصيب يرتفع وزنه، والذي يخطئ ينخفض.
3. **أوزان لكل نظام سوق**: يعرف من هو الأفضل في `QUIET` و`TREND` و`HIGH_VOL`.
4. **Page-Hinkley**: عند اكتشاف انجراف يعيد ضبط الأوزان ويرفع سرعة التعلّم.
5. **Meta Filter**: بوابة تتعلّم من نتائج الصفقات المشابهة وترفض غير المجدي.
6. **تسوية الأوزان**: سقف `30%` وأرضية `2%` لكل خبير، فلا يبتلع خبير واحد القرار.

## قواعد عدم التطلّع للمستقبل

هذه أشدّ نقطة في المشروع، ومحميّة باختبارات:

```
شمعة t  →  حساب الميزات  →  الإشارة  →  القرار
                                        │
                                        ▼
                            التنفيذ عند فتح شمعة t+1
                                        │
                                        ▼
                          SL/TP يُمسحان شمعة بشمعة
                                        │
                                        ▼
              التعلّم من نتيجة اكتملت سابقًا فقط (t − h_max)
```

- عند التباس الشمعة (ضربت SL وTP معًا) يُحسب **SL أولًا** — سياسة محافظة عن قصد.
- الرسوم والانزلاق والفائدة التمويلية تُطبّق في مواضعها الصحيحة.
- في Walk-Forward يُجمّد النموذج في مرحلة الاختبار تمامًا (مختبَر آليًا).

## حالة البحث — بصراحة

على البيانات **الصناعية** المتاحة في بيئة التطوير:

- الأنظمة التكيّفية لم تتفوق بعد على **Ensemble ثابت الأوزان** في Walk-Forward، وبعض القطع جاءت سلبية.
- أي أن **التعقيد لم يُثبت قيمته بعد** على هذه البيانات تحديدًا.
- السبب المرجّح: البيانات صناعية، وسياسة SL-أولًا تجعل الاختبار قاسيًا عن قصد.
- **الحكم النهائي يجب أن يكون على بيانات بينانس الحقيقية** عبر `train_and_report.py`.

> كل مكوّن في FUGU-MAX يجب أن يُثبت فائدته تجريبيًا، لا أن يُقبل لأن اسمه يبدو متقدّمًا.
